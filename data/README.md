# CNC CRT to LCD Compatibility Database

Open data set mapping OEM CRT display part numbers to their LCD replacement modules for industrial CNC machines.

## Files

- `cnc-crt-to-lcd-compatibility.csv` — 45 models, 8 brands (CSV)
- `cnc-crt-to-lcd-compatibility.json` — Same data in JSON format

## Brands Covered

FANUC (14), Mitsubishi (8), Mazak (6), Siemens (4), Haas (4), Toshiba (3), Okuma (3), Heidenhain (3)

## Fields

| Field | Description |
|-------|-------------|
| brand | Manufacturer (FANUC, Mitsubishi, etc.) |
| crt_model | Original CRT part number |
| size_type | Screen size and display type |
| cnc_system | Compatible CNC control systems |
| lcd_replacement | Recommended LCD replacement module |
| resolution | LCD display resolution |
| status | Availability status |
| url | Product page link |

## Source

Data compiled by [Kongto Technology](https://cncdisplay.com) — 12 years of CNC industrial display upgrade expertise.
