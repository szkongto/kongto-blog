三、排名恢复行动方案

重要前提：排名恢复不会立即生效。谷歌需要重新爬取旧 URL 的新 301 目标、重新收录， 通常需要 2-8 周。但修复越早，恢复越快——每多一天错误重定向在线，就多一天权重流失。

第二阶段：验证与提交（修复后 1-3 天）

  1. curl 活站逐条验证：对修复的每条规则，curl 确认 301 → 200 链路完整
  2. Google Search Console 提交：在 GSC 的 URL 检查工具中，手动提交关键旧 URL 请求重新爬取
  3. GSC 覆盖率报告：检查"已排除"和"错误"标签下是否有这些旧 URL 的记录
  4. sitemap 更新：确保所有正确目标页面都在 sitemap 中

第三阶段：中期恢复（2-8 周）

  1. 每周检查 GSC：观察修复后的 URL 是否被重新爬取和收录
  2. 监控关键词排名：用 GSC 性能报告跟踪 0093、BM09DF、DR5614、转换器等关键词的展示次数和排名变化
  3. 内链优化：在首页和品牌页添加指向这些恢复页面的内部链接，加速权重传递
  4. 外链建设：如果有外部链接指向旧 URL，联系对方更新为新 URL（301 会传权重但直接链接更好）

第四阶段：长期防护

  1. 建立重定向审计 SOP：每次修改 _redirects 后，运行审计脚本验证：(a) 目标文件存在 (b) 型号匹配 (c) 无→首页/品牌页的丢权重规则
  2. 部署前验证门禁：在 GitHub Actions 的 deploy-worker job 中加入自动检查：如果新规则包含→/index.html 或→/brands/，报警阻止部署
  3. 定期全站审计：每月运行一次 scripts/audit_full.py 和 scripts/deep_audit.py
