Toshiba CRTs in FANUC Systems

Toshiba manufactured CRT displays for FANUC CNC systems as an OEM supplier. The Toshiba D9MM-11A and D14CM-01A are functionally identical to FANUC's own A61L series displays — same connector (Honda MR-20M), same pinout, same mounting dimensions, same video signal. This means any LCD replacement designed for the FANUC A61L-0001-0093 or A61L-0001-0096 will also fit the equivalent Toshiba models.

Installation Notes

  1. Verify your machine uses a Honda MR-20M 20-pin connector (standard on FANUC 0/0i/16i/18i series)
  2. Power off the machine and disconnect the 20-pin cable from the Toshiba CRT
  3. Remove the CRT mounting bracket and replace with the LCD module bracket
  4. Connect the 20-pin cable to the LCD module — pins are 1:1 compatible
  5. Secure the LCD module with the same screws — no drilling or adapters needed
  6. Power on — boot screen appears immediately
