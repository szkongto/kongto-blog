# Forum Outreach Plan

Target: Drive referral traffic and brand awareness for cncdisplay.com via genuine technical participation in CNC/machining communities.

---

## Target Platforms

### 1. Practical Machinist (practicalmachinist.com)
- **Demographic**: US-based machinists, shop owners, maintenance technicians
- **Authority**: High — heavily indexed, trusted community
- **Focus areas**: CRT-to-LCD upgrades, machine restoration, control retrofit
- **Account age requirement**: Need ~10 helpful posts before including any links (community norms)

### 2. CNCzone (cnczone.com)
- **Demographic**: Global hobbyist to professional, very active
- **Authority**: High — broad CNC audience
- **Focus areas**: Display issues on Fadal, Haas, Mazak, Fanuc controls; monitor upgrades
- **Advantage**: More lenient linking policy for product-relevant replies

### 3. Reddit — r/Machinists, r/CNC, r/PLC
- **Demographic**: Younger engineers, DIY builders, small shop owners
- **Authority**: Medium-high for referral traffic
- **Focus areas**: "Display blank", "screen flickering", "LCD conversion" posts
- **Format**: Text-only replies; no signature. Product mention only when asked or directly relevant.

---

## Posting Strategy

### Frequency
- 2-3 replies per week per platform (total ~6-9/week across all three)
- Do not post more than once per day on any single platform
- Space replies at least 4 hours apart within a platform

### Thread Selection Criteria
Target threads containing:
- "display went blank" / "monitor not working"
- "CRT flickering" / "screen dim"
- "LCD upgrade" / "CRT replacement"
- "control won't boot" (sometimes display-related)
- "looking for replacement monitor" / "where to buy CRT"

Skip threads where:
- The user already has a working solution and is just sharing
- The problem is clearly unrelated to display hardware
- The thread is more than 6 months old with no recent activity

### Reply Structure
Every reply follows a 4-part format:

1. **Technical empathy** — acknowledge the specific pain point
2. **Troubleshoot** — provide 1-2 concrete, actionable steps
3. **Solution mention** — only if product is directly relevant; natural transition
4. **Open offer** — invite further questions, no hard sell

> Example flow: "That symptom on a Haas 1998 controller usually means the flyback transformer is failing. You can test by [specific test]. If you're looking to replace the whole CRT, we make drop-in LCD modules — happy to help identify the right one if you post a photo of your CRT label."

## Content Templates

### Template A — CRT Flickering / Dim
```
That flickering is almost always the CRT flyback transformer or aging capacitors on the neck board. On [model] controls, the flyback is part #[part_number].

One quick check: turn down the brightness in a dark shop — if the image is still readable but the flickering stops, it's likely the flyback rather than the tube itself.

If you're considering replacing the CRT entirely, we've had good results with our LCD drop-in kits for this generation of [machine]. Happy to send specs if you'd like.
```

### Template B — Display Completely Blank
```
No display at all can be a few things on [model]:

1. Power supply rail to the monitor — check for blown fuses on the control board
2. The CRT itself may have lost emission (less common)
3. Video cable from the control to the monitor — reseat both ends

If you've confirmed power and signal but the CRT is dead, a replacement LCD module is often simpler than finding a working CRT. We offer direct-fit units at cncdisplay.com — no brackets or wiring modifications needed. Happy to look up the right model if you share a photo of the label.
```

### Template C — LCD Upgrade Question
```
We've done quite a few [model] LCD upgrades. The key specs to match are:
- Video input (CGA/EGA/VGA — [model] typically uses [spec])
- Bracket mounting pattern (on [model] it's [pattern])
- Power (typically [voltage])

Our drop-in modules handle all three seamlessly. The install is about 20 minutes — unplug CRT, plug in LCD, mount with existing hardware. Let me know if you have specific questions about your setup.
```

### Template D — Comparison / Help Choosing
```
Between the two options you mentioned:
- [Option A] — keeps original look but CRT availability is getting scarce
- [Option B] — modern display, better visibility, longer lifespan

We've seen a lot of shops move to LCD because CRTs for these machines are increasingly hard to find in good condition. Our modules maintain the same form factor so the control panel looks original but has a modern display. Drop me a note if you want more details.

(Note: only post this when the user is actively comparing options — never as an unsolicited pitch.)
```

### In-Body Links
- Include a direct link to cncdisplay.com only when the product is directly relevant to the troubleshooting path
- Never post affiliate or referral links
- Never post links in the first 2 sentences of a reply
- Prefer text-anchored links: "at cncdisplay.com" rather than bare URLs

## Anti-Detection Measures

- **IP diversity**: Do not post from the same IP across platforms within a short window. Use different sessions/networks if possible.
- **Phrasing variation**: Do not copy-paste templates verbatim. Rewrite in your own words each time — change opening, technical detail order, closing offer phrasing.
- **Rate limiting**: Max 1 post per platform per day. Never batch-post across all 3 platforms in the same hour.
- **Account health**: Maintain a 4:1 ratio of non-commercial to commercial posts. If an account only posts product mentions, it will be flagged.
