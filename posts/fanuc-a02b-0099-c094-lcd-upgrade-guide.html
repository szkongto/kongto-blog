Overview

The FANUC Series 0-P (also known as the A02B-0099-C094) is a monochrome green-phosphor CRT display assembly used on the classic FANUC 0 series and 0-Mate CNC controls. This 9-inch PBM (Panel Built-in Monitor) unit was standard equipment on countless machine tools from the 1980s through 1990s.

Original CRT Display

The original CRT display in the A02B-0099-C094-LCD is a 9-inch CRT unit with 20-pin Honda MR-20M interface. Key characteristics of the original CRT include:

  • Resolution: 640x400 or 640x480 pixels
  • Brightness: Approximately 200 cd/m² (degrades over time)
  • Lifespan: 15,000-20,000 hours typical
  • Power: DC 24V, approximately 40-60W
  • Signal: TTL-level RGB via 20-pin Honda MR-20M

Installation Guide

  1. Power off the CNC machine and lockout/tagout per safety procedures
  2. Remove CRT housing: Unscrew the 4 mounting screws, disconnect signal and power cables
  3. Mount LCD module: Position the LCD module in the same opening, secure with original screws
  4. Connect cables: Plug the original signal cable into the LCD module port, reconnect DC 24V power
  5. Power on and test: Restore power. The LCD will display automatically. Adjust brightness/contrast using OSD buttons if needed

Note: No CNC parameter changes, no wiring modifications, no special tools required. Total installation time: 15-30 minutes.
